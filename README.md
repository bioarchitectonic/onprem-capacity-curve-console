# On-Prem Capacity Curve · Dataset Console v1

One self-contained web page (English / Korean) that draws the values of record of the On-Prem Capacity Curve study: steady decode throughput against wall power for a 27B and a 9B model at twelve quantization rungs on four unified-memory machines (DGX Spark, Mac mini, MacBook Pro, MacBook Air), with the per-cell frame (decode, wall, gross and net energy, E8, accuracy), the event log, the cell stack on the pass clock, the power-supply A/B and the axis-2 results.

**Open it:** `onprem-capacity-curve-dataset-console_EN-KO_20261106.html` — any browser, no server, no network. `index.html` only redirects to it.

**Data of record:** the measurement records behind every number on the page are deposited on Zenodo, DOI [10.5281/zenodo.23997826](https://doi.org/10.5281/zenodo.23997826) — 566 data files with SHA-256 sums and a redaction map. This repository holds the console page only; it is byte-identical to the copy in the deposit (sha256 `715a2050edf05944d264c4c8d21a581e0ac9610f96609fc2cb36a6aba3236f0a`).
